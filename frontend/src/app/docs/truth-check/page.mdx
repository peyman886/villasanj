| ---------------------------------------- | --------------------------------------------------------------------------------------- |

**قاعده‌ی بهترین حالت:** حکم «نمی‌خواند» فقط وقتی داده می‌شود که حتی بهترین حالت شواهد ادعا را رد
کند (قاعده‌ی ۵ محصول). نزدیک‌تر بودن از ادعا، یا کم‌گویی («بیشتر از ۳۰ دقیقه»)، هرگز رد نمی‌شود.

## ادعاهای فاصله

- **خواندن ادعا:** مقدار منتشرشده یک انتخاب گردشده از فهرست کوتاه پلتفرم است (جاباما: زیر ۵، ۵،
  ۱۰ … ۳۰، بیشتر از ۳۰ دقیقه؛ شب: ۵، ۱۵، ۳۰، ۶۰). پس «N دقیقه» یعنی تا N + max(5, N/2) دقیقه (A15).
- **تبدیل زمان به فاصله:** با سرعت‌های سخاوتمندانه‌ی خط مستقیم: پیاده ۴۰ تا ۱۰۰ متر در دقیقه، ماشین
  ۱۵۰ تا ۱۰۰۰ متر در دقیقه (A13). وقتی شیوه معلوم نیست، هر دو برداشت سنجیده می‌شود.
- **دریا یک کلمه‌ی کامل است:** «دریاسر» (یک دشت) و «ساحلی» در «پیاده‌راه ساحلی» دریا نیستند، و
  مقداری که برای دو مکان آمده («جنگل و دریا») سنجیده نمی‌شود.
- **بازه روی موقعیت مبهم:** فاصله‌ی کل دایره‌ی ابهام تا ساحل یا مکان؛ شرح در
  [داده‌ی جغرافیایی](/docs/geo).
- **نقشه‌ی ناقص فقط تأیید می‌کند:** مغازه، رستوران، مرکز درمانی و جنگل؛ مرکز شهر کامل است و می‌تواند
  رد کند.

نمونه‌های ردشده بیش‌ادعایی‌های روشن‌اند؛ مثلاً «زیر ۵ دقیقه پیاده تا دریا» در حالی که کل دایره‌ی ابهام

خواندن دستی پیدا شدند و حالا تست واحدند.

## ادعاهای امکانات

- **اول قواعد:** واژه‌نامه‌ی امکانات مشترک با جستجو (`config/features.toml`)، با نفی («استخر ندارد»)
  و امکان مشاع. هر ادعا نقل‌قول عینی از متن دارد.
- **مدل زبانی فقط برای باقی‌مانده:** جمله‌هایی که قواعد نتوانستند بخوانند. نقل‌قولی که عیناً در متن
  نیست یک بار برمی‌گردد و بعد کنار می‌رود.
- **ارزیابی روی ۶۰ توضیح برچسب‌خورده‌ی مالک (claims-v1):** دقت ۹۳٫۷٪ (۸۴٫۸ تا ۹۷٫۵٪) و بازیابی
  ۸۰٫۸٪ (۷۰٫۳ تا ۸۸٫۲٪)؛ همه‌ی نقل‌قول‌ها عینی. معیار ۱ از M9 (دقت ≥ ۹۰٪، بازیابی ≥ ۸۰٪) پاس شد.
  منبع: `enrichment claims-eval`، ۱۱ مهر.
- **شاهد:** فهرست امکانات همان آگهی («با فهرست امکانات می‌خواند» یا «نمی‌خواند»)، و عکس‌ها.

## شاهد عکس

برچسب‌های صفر-نمونه‌ی SigLIP 2 روی هر عکس، با آستانه‌ای که در آن دقت هر عکس روی برچسب‌های مالک
≥ ۸۵٪ است (۳۳۶ عکس، photos-v1، ۱۱ مهر):

| برچسب        | دقت (بازه‌ی ۹۵٪)      | بازیابی | استفاده |
| ------------ | --------------------- | ------- | ------- |
| استخر        | ۹۴٫۰٪ (۸۳٫۸ تا ۹۷٫۹٪) | ۹۷٫۹٪   | بله     |
| جکوزی        | ۸۶٫۰٪                 | ۸۷٫۵٪   | بله     |
| جنگل         | ۸۷٫۰٪                 | ۷۲٫۷٪   | بله     |
| باربیکیو     | ۸۸٫۹٪                 | ۸۴٫۲٪   | بله     |
| منظره‌ی دریا | به ۸۵٪ نرسید          | —       | نه      |
| شومینه       | به ۸۵٪ نرسید          | —       | نه      |

عکس فقط **پشتیبان** است (A21): امکانی که توضیح ادعا کرده و عکس نشانش می‌دهد «تأیید شد» با منبع عکس
می‌گیرد؛ برچسب عکس به‌تنهایی هیچ چیز را تأیید نمی‌کند و هرگز بر «ندارد» غلبه نمی‌کند. دلیلش این است
که پنج عکس هر آگهی پنج فرصت برای مثبت کاذب است، پس دقت در سطح آگهی از دقت هر عکس کمتر است.

<Callout kind="caution" title="بررسی تصویری با مدل بینایی: ساخته و سنجیده شد، استفاده نمی‌شود">
  برای منظره‌ی دریا و شومینه یک مدل بینایی (gemini-3.1-flash-lite، هر عکس یک فراخوانی) روی همان ۳۳۶
  عکس برچسب‌خورده‌ی مالک پرسیده شد (۱۶ مهر، حدود ۰٫۲ دلار). دقت در برابر برچسب‌ها: منظره‌ی دریا ۳۵
  از ۴۸ (حدود ۷۳٪) با بازیابی کامل، شومینه ۱۸ از ۲۶ (حدود ۶۹٪)؛ هیچ‌کدام به ۸۵٪ نرسید و هیچ
  آستانه‌ای ذخیره نشد. نگاه به چهار مورد «مثبت کاذب» نشان داد هر چهار عکس واقعاً دریا یا شومینه
  دارند و برچسب آن را نزده بود، پس دقت واقعی مدل احتمالاً بالاتر است؛ ولی قاعده این است که برچسب
  مالک داور است، پس این دو برچسب استفاده نمی‌شوند تا مالک برچسب‌ها را بازبینی کند.
</Callout>

## ناهمخوانی بین پلتفرم‌ها و H4

دو آگهی یک ویلا «ناهمخوان» حساب می‌شوند فقط وقتی آنچه خود پلتفرم‌ها می‌گویند (فهرست امکانات،
توضیح) روی یکی «بله» و روی دیگری «نه» باشد و هر کدام روی پلتفرم خودش بی‌معارض باشد، یا وقتی
ادعاهای فاصله‌ی آن‌ها تا یک مقصد نام‌دار با هیچ برداشتی هم‌پوشانی نداشته باشند (A23). نقشه و عکس
شاهدند، نه گفته. صفحه‌ی ویلا هر دو طرف را با منبعش نشان می‌دهد، بدون قضاوت که کدام درست است.

H4 می‌پرسید چه سهمی از آگهی‌ها دست‌کم یک ادعا دارند که نقشه رد می‌کند یا آگهی همان ویلا در پلتفرم
دیگر خلافش را می‌گوید. گزارش پژوهشی ≥ ۲۵٪ را انتظار داشت:

H4 تأیید نشد: سهم واقعی حدود یک‌دهم یا کمتر است. ویلاهای دوپلتفرمی از ساخت فعلی ویلاها (با سیاست
پس از اصلاح برچسب‌ها) می‌آیند.

## بازتولید

```bash
cd backend
uv run villasanj enrichment claims             # پوشش parse ادعاهای فاصله
uv run villasanj enrichment features           # ادعاهای توضیح در برابر فهرست امکانات
uv run villasanj enrichment truth-sea          # ادعاهای دریا در برابر خط ساحل
uv run villasanj enrichment truth-distances    # بقیه‌ی مقصدها در برابر مکان‌های OSM
uv run villasanj enrichment photo-tags-eval    # آستانه‌ی برچسب‌های عکس روی برچسب‌های مالک
uv run villasanj enrichment h4 --out ../reports/h4-<date>.md
```
