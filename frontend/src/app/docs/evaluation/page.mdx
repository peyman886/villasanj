## روش

- **وزن طبقه:** gold set طبقه‌بندی‌شده است؛ دقت و بازیابی با وزن جمعیت هر طبقه حساب می‌شوند.
- **بازه‌ی Wilson ۹۵٪** برای هر نسبت، با اندازه‌ی مؤثر نمونه وقتی وزن‌ها برابر نیستند.
- **H1 اصلاح‌شده:** تعداد واقعی جفت‌ها ≈ پیش‌بینی × دقت / بازیابی؛ بازه از دو سر بازه‌های دقت و
  بازیابی می‌آید و به اندازه‌ی پلتفرم کوچک‌تر محدود می‌شود (خودش بازه‌ی ۹۵٪ نیست).
- **H2 و H3 روی برداشت هم‌زمان:** فقط شب‌هایی که هر دو پلتفرم با کمتر از ۶ ساعت فاصله دیده‌اند.
- **سیاست تطبیق:** جفت‌ها از همان سیاست تصمیم تولید می‌آیند (`config/er.toml`)، و دقت و بازیابی‌ای
  که برای اصلاح H1 به کار می‌رود، سرتاسری روی gold با برچسب‌های اعمال‌نشده است.
- **تکرارپذیری:** هر گزارش match run و dataset hash را دارد؛ اجرای دوباره همان خروجی را می‌دهد.
