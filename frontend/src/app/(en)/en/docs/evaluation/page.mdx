## Method

- **Stratum weights:** the gold set is stratified; precision and recall are weighted by each
  stratum's population.
- **95% Wilson interval** for every proportion, with the effective sample size when weights are
  unequal.
- **Corrected H1:** true pair count ≈ predictions × precision / recall; the range comes from the
  ends of the precision and recall intervals and is capped at the size of the smaller platform (it
  is not itself a 95% interval).
- **H2 and H3 on the same-window capture:** only nights that both platforms showed less than 6 hours
  apart.
- **Matching policy:** pairs come from the same decision policy the product uses
  (`config/er.toml`), and the precision and recall used to correct H1 are end-to-end, on the gold
  set without applying the labels.
- **Reproducibility:** every report records its match run and dataset hash; rerunning gives the same
  output.
