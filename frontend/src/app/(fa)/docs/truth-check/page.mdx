**قاعده‌ی بهترین حالت:** حکم «نمی‌خواند» فقط وقتی داده می‌شود که حتی بهترین حالت شواهد هم ادعا را
رد کند (قاعده‌ی ۵ محصول). نزدیک‌تر بودن از آنچه ادعا شده، یا کم‌گفتن («بیشتر از ۳۰ دقیقه»)، هرگز
رد نمی‌شود.

## ادعاهای فاصله

- **خواندن ادعا:** مقدار منتشرشده گزینه‌ای گردشده از فهرست کوتاه پلتفرم است (جاباما: زیر ۵، ۵،
  ۱۰ … ۳۰، بیشتر از ۳۰ دقیقه؛ شب: ۵، ۱۵، ۳۰، ۶۰). پس «N دقیقه» یعنی تا N + max(5, N/2) دقیقه (A15).
- **تبدیل زمان به فاصله:** با سرعت‌های سخاوتمندانه‌ی خط مستقیم: پیاده ۴۰ تا ۱۰۰ متر در دقیقه، ماشین
  ۱۵۰ تا ۱۰۰۰ متر در دقیقه (A13). وقتی شیوه معلوم نیست، هر دو برداشت سنجیده می‌شود.
- **دریا فقط به‌صورت کلمه‌ی کامل:** «دریاسر» (نام یک دشت) و «ساحلی» در «پیاده‌راه ساحلی» دریا
  نیستند، و مقداری که برای دو مکان با هم آمده («جنگل و دریا») سنجیده نمی‌شود.
- **بازه روی موقعیت مبهم:** فاصله‌ی کل دایره‌ی ابهام تا ساحل یا مکان سنجیده می‌شود؛ شرحش در
  [داده‌ی جغرافیایی](/docs/geo) است.
- **نقشه‌ی ناقص فقط تأیید می‌کند:** برای مغازه، رستوران، مرکز درمانی و جنگل. داده‌ی مرکز شهر کامل
  است و می‌تواند ادعا را رد کند.

بازخوانی دستی پیدا شدند و حالا هر کدام یک تست واحد دارند.

- **اول قواعد:** واژه‌نامه‌ی امکانات، مشترک با جستجو (`config/features.toml`)، همراه با نفی («استخر

- **مدل زبانی فقط برای باقی‌مانده:** جمله‌هایی که قواعد نتوانستند بخوانند. نقل‌قولی که عیناً در متن
  نباشد یک بار به مدل برمی‌گردد و بعد کنار گذاشته می‌شود.
- **ارزیابی روی ۶۰ توضیح برچسب‌خورده‌ی مالک (claims-v1):** دقت ۹۳٫۷٪ (۸۴٫۸ تا ۹۷٫۵٪) و بازیابی
  ۸۰٫۸٪ (۷۰٫۳ تا ۸۸٫۲٪)؛ همه‌ی نقل‌قول‌ها عینی. معیار ۱ از M9 (دقت ≥ ۹۰٪، بازیابی ≥ ۸۰٪) پاس شد.
  منبع: `enrichment claims-eval`، ۱۱ مهر.
- **شاهد:** فهرست امکانات همان آگهی («با فهرست امکانات می‌خواند» یا «نمی‌خواند») و عکس‌ها.

## شاهد عکس

هر عکس با SigLIP 2 به‌صورت zero-shot برچسب می‌خورد، با آستانه‌ای که دقت هر عکس را روی برچسب‌های
مالک به ≥ ۸۵٪ می‌رساند (۳۳۶ عکس، photos-v1، ۱۱ مهر):

| برچسب        | دقت (بازه‌ی ۹۵٪)      | بازیابی | استفاده |
| ------------ | --------------------- | ------- | ------- |
| استخر        | ۹۴٫۰٪ (۸۳٫۸ تا ۹۷٫۹٪) | ۹۷٫۹٪   | بله     |
| جکوزی        | ۸۶٫۰٪                 | ۸۷٫۵٪   | بله     |
| جنگل         | ۸۷٫۰٪                 | ۷۲٫۷٪   | بله     |
| باربیکیو     | ۸۸٫۹٪                 | ۸۴٫۲٪   | بله     |
| منظره‌ی دریا | به ۸۵٪ نرسید          | -       | نه      |
| شومینه       | به ۸۵٪ نرسید          | -       | نه      |

عکس فقط **پشتیبان** است (A21): امکانی که توضیح ادعا کرده و عکس هم نشانش می‌دهد، «تأیید شد» با منبع
عکس می‌گیرد؛ برچسب عکس به‌تنهایی چیزی را تأیید نمی‌کند و هرگز بر «ندارد» غلبه نمی‌کند. دلیلش این است
که پنج عکس هر آگهی پنج فرصت برای مثبت کاذب است، پس دقت در سطح آگهی از دقت در سطح عکس کمتر است.

<Callout kind="caution" title="بررسی تصویری با مدل بینایی: ساخته و سنجیده شد، استفاده نمی‌شود">
  برای منظره‌ی دریا و شومینه، یک مدل بینایی (gemini-3.1-flash-lite، یک فراخوانی برای هر عکس) روی
  همان ۳۳۶ عکس برچسب‌خورده‌ی مالک آزموده شد (۱۶ مهر، حدود ۰٫۲ دلار). دقت در برابر برچسب‌ها: منظره‌ی
  دریا ۳۵ از ۴۸ (حدود ۷۳٪) با بازیابی کامل، و شومینه ۱۸ از ۲۶ (حدود ۶۹٪). هیچ‌کدام به ۸۵٪ نرسید و
  آستانه‌ای ذخیره نشد. بازبینی چهار مورد «مثبت کاذب» نشان داد هر چهار عکس واقعاً دریا یا شومینه
  دارند و فقط برچسبش زده نشده بود؛ پس دقت واقعی مدل احتمالاً بالاتر است. ولی قاعده این است که برچسب
  مالک داور است، پس تا مالک برچسب‌ها را بازبینی نکرده، این دو برچسب استفاده نمی‌شوند.
</Callout>

## ناهمخوانی بین پلتفرم‌ها و H4

دو آگهی یک ویلا فقط وقتی «ناهمخوان» حساب می‌شوند که گفته‌ی خود پلتفرم‌ها (فهرست امکانات، توضیح) روی
یکی «بله» و روی دیگری «نه» باشد و هر کدام روی پلتفرم خودش معارضی نداشته باشد، یا ادعاهای فاصله‌شان
تا یک مقصد نام‌دار با هیچ برداشتی هم‌پوشانی نداشته باشد (A23). نقشه و عکس شاهدند، نه گفته. صفحه‌ی
ویلا هر دو طرف را با منبعشان نشان می‌دهد و درباره‌ی درستی هیچ‌کدام قضاوت نمی‌کند.

H4 می‌پرسید چه سهمی از آگهی‌ها دست‌کم یک ادعا دارند که نقشه ردش می‌کند یا آگهی همان ویلا در پلتفرم
دیگر خلافش را می‌گوید. گزارش پژوهشی دست‌کم ۲۵٪ را انتظار داشت:

پس از اصلاح برچسب‌ها) گرفته شده‌اند.

## بازتولید

```bash
cd backend
uv run villasanj enrichment claims             # پوشش parse ادعاهای فاصله
uv run villasanj enrichment features           # ادعاهای توضیح در برابر فهرست امکانات
uv run villasanj enrichment truth-sea          # ادعاهای دریا در برابر خط ساحل
uv run villasanj enrichment truth-distances    # بقیه‌ی مقصدها در برابر مکان‌های OSM
uv run villasanj enrichment photo-tags-eval    # آستانه‌ی برچسب‌های عکس روی برچسب‌های مالک
uv run villasanj enrichment h4 --out ../reports/h4-<date>.md
```
